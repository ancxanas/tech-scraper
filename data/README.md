# data/

## gsmarena-index.json

A local index of ~1,180 phone models: name, brand and GSMArena slug. Built once
with `deno task index` so fresh clones can match models without hitting the
network.

**Provenance and terms.** The slugs point at GSMArena's public spec pages, and
the richer spec data this tool reads (via `src/knowledge/gsmarena.ts`) is
fetched at run time from those pages, then cached locally under `.cache/`.
GSMArena's terms prohibit scraping and redistribution, so:

- This repository ships only the slim name/slug index needed to _find_ pages,
  not their contents.
- Do not redistribute `gsmarena-index.json` or any cached page text.
- For a production deployment, rebuild the index yourself (`deno task index`)
  against the live site and review the source's current terms first.

Everything else in this directory is generated by this repo's own collectors
from BrightData snapshots of marketplace search results.
